# PPT Script Caption — 한국어 안내서

**[English README](README.md)** | **한국어 사용설명서**

**PPT Script Caption은 발화장애·구음장애·언어장애가 있는 사용자를 위한 무료 오픈소스 Windows 발표 보조 프로그램**입니다. 미리 작성한 **PowerPoint 발표자 노트**를 발표 진행에 맞춰 자막으로 보여주므로, Zoom·Google Meet 온라인 세미나, 강의, 학술 발표 등에서 음성인식 없이도 자신의 원고를 참석자에게 전달할 수 있습니다.

발표자는 **이전·현재·다음 자막**을 확인하고 키보드나 매크로 키패드로 진행하며, 참석자는 공유된 PPT 화면과 **현재 자막만** 볼 수 있습니다. 발화에 제약이 없는 발표자도 준비한 원고를 활용하는 발표 보조 도구로 사용할 수 있습니다.

**검색 키워드:** 발화장애, 구음장애, 언어장애, 장애인 접근성, 보조공학, 발표 보조, 발표 보조 프로그램, PPT 자막, 파워포인트 자막, 발표자 노트, 발표 스크립트, 온라인 발표, 온라인 세미나, 화상회의 자막, Zoom 자막, Google Meet 자막.

> **참고:** 현재 자막은 사전에 작성한 원고를 수동으로 진행시키는 방식입니다. 음성인식·자동 번역·TTS는 아직 구현되지 않았고 향후 개발 계획에 포함되어 있습니다.

> **v0.2.0 — 공개 소스 시험판.** Windows/PowerPoint 실사용 검증을 계속하는 단계이며, 서명된 설치 프로그램이나 완전히 검증된 배포판은 아닙니다.

## 주요 기능

- **버튼 하나로 발표 진행:** F8을 누르면 다음 자막, 해당 슬라이드의 마지막 자막에서는 다음 PPT 슬라이드로 이동합니다. F7은 이전 방향입니다.
- **발표자 전용 화면:** 이전·현재·다음 원고와 남은 자막 개수를 함께 표시합니다.
- **참석자용 독립 출력창:** PowerPoint 슬라이드 쇼 화면과 현재 자막만 합쳐 Zoom 또는 Google Meet에서 창 공유합니다.
- **한국어/English 인터페이스:** 발표자 화면의 언어 선택에서 바로 바꾸고 다음 실행에도 유지됩니다.
- **성능 진단:** 실측 캡처 FPS, Qt 화면 표시 FPS, 사용 중인 캡처 엔진, 슬라이드 쇼 창 해상도를 확인할 수 있습니다.
- **참석자 화면에도 진단 표시 가능:** 체크박스로 켜고 끕니다. 기본값은 **끔**입니다.
- **자막 크기:** F10은 축소, F11은 확대. 설정은 자동 저장됩니다.
- **로컬 처리:** 발표자 노트와 수정한 자막을 외부 서버로 전송하지 않습니다.
- **캡처 방식:** DXcam WinRT → DXGI → MSS 순서로 시도하며 필요하면 MSS를 고정할 수 있습니다.

## 아직 지원하지 않는 기능

- **개인 맞춤형 AI 음성인식:** 향후 목표이며 미구현입니다.
- **자동 번역:** 미구현입니다. **프로그램 언어를 영어로 바꿔도 발표자 노트·자막 내용이 영어로 번역되지는 않습니다.**
- Zoom/Meet와의 직접 연동 API는 없습니다. 해당 회의 앱에서 일반적인 **창 공유**를 사용합니다.
- 30fps·60fps를 보장하지 않습니다. 화면에 표시되는 FPS는 목표값이 아닌 **실측값**입니다.
- Python/Qt가 재캡처하는 구조라 PowerPoint 안에 포함된 동영상이 다소 끊길 수 있습니다. 음성은 별도로 회의 앱의 컴퓨터 오디오 공유 설정을 확인해야 합니다.

## 준비물

- Windows 10 또는 Windows 11
- **설치형 Microsoft PowerPoint** (웹 버전은 지원하지 않음)
- Python 3.12 이상 (Python 3.14에서도 현장 시험한 이력이 있음)
- 슬라이드별 발표자 노트가 들어 있는 `.pptx`
- 가급적 2개 모니터. PPT 슬라이드 쇼 창이 가려지거나 최소화되지 않아야 정상 캡처될 수 있습니다.

### 설치 및 실행 — Windows CMD

이 프로젝트 폴더에서 다음을 실행하세요. Python 3.12라면 첫 줄의 `3.14`만 `3.12`로 바꾸면 됩니다.

```bat
cd /d C:\path\to\PPTScriptCaption
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

이미 `.venv` 가상환경이 만들어져 있다면 다음만 실행해도 됩니다.

```bat
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

### 발표 및 화면 공유

1. PowerPoint에서 발표할 `.pptx` 파일을 엽니다.
2. **슬라이드 쇼 → 슬라이드 쇼 설정 → 웹 형식으로 진행(창)**으로 설정하고 슬라이드 쇼를 시작합니다.
3. PPT Script Caption에서 **PowerPoint 연결**을 누릅니다.
4. **참석자 화면 열기**를 눌러 별도 출력창을 엽니다.
5. Zoom 또는 Google Meet에서 **참석자 출력창만** 공유합니다. 발표자 제어창은 공유하지 않습니다.
6. F7~F11 또는 같은 키가 지정된 매크로 키패드로 발표합니다.

| 키 | 동작 |
| --- | --- |
| **F7** | 이전 자막 / 첫 자막일 때 이전 슬라이드 |
| **F8** | 다음 자막 / 마지막 자막일 때 다음 슬라이드 |
| **F9** | 참석자용 자막 숨기기/표시하기 |
| **F10** | 참석자용 글자 크기 2px 축소 |
| **F11** | 참석자용 글자 크기 2px 확대 |

**전역 단축키**로 처리하므로 별도의 PPT 창이나 자막 창을 일일이 활성화할 필요가 없도록 설계되었습니다. 다른 프로그램이 같은 키를 점유하면 등록에 실패할 수 있습니다.

### 발표자 노트와 자막 분할

발표자 노트의 문장을 자동으로 나누거나, 노트 안의 `//`로 자막 구간을 직접 지정할 수 있습니다.

```text
이 시스템은 레이더로 수면 변화를 감지합니다. //
관측 결과는 현장 모니터링 화면에 표시됩니다. //
마지막으로 향후 적용 계획을 말씀드리겠습니다.
```

자막 편집창에서 한 줄에 하나씩 고쳐서 **자막 저장**을 누르면 PPT와 같은 폴더에 `.pptcaptions.json` 파일을 만듭니다. **PPT 원본 파일은 수정하지 않습니다.** 해당 JSON에는 원고와 PPT 파일 경로가 들어갈 수 있으므로 GitHub에 업로드하지 마세요.

### 한국어/영어 전환

발표자 창 오른쪽의 **언어 / Language** 콤보박스에서 `한국어` 또는 `English`를 선택합니다. 버튼, 안내문, 상태 표시, 경고 창 등 인터페이스를 전환합니다. 설정 파일은 다음 위치에 저장됩니다.

```text
%APPDATA%\PPTScriptCaption\settings.json
```

**발표 원고의 언어는 바뀌지 않습니다.** 향후 자동 번역 기능을 구현할 때 별도 옵션으로 제공할 계획입니다.

### 실측 FPS와 캡처 상태

발표자 화면에서 다음과 같은 진단 정보를 볼 수 있습니다.

```text
캡처: 19.8fps  |  표시: 19.4fps  |  MSS  |  1600×900
```

- **캡처 FPS:** 캡처 스레드에서 실제 획득한 프레임 수를 경과 시간으로 나눈 값입니다.
- **표시 FPS:** 캡처된 영상 프레임이 참석자용 Qt 화면에 실제 전달된 속도입니다. **Zoom/Meet 시청자에게 전송된 최종 FPS와는 다릅니다.**
- **캡처 엔진:** `DXcam WINRT`, `DXcam DXGI`, `MSS` 중 현재 사용 중인 방식입니다.
- **해상도:** 캡처 대상 PowerPoint 슬라이드 쇼 창 크기입니다.

**참석자 화면에도 FPS/캡처 상태 표시**를 체크하면 송출 화면 왼쪽 위에도 작은 진단 정보를 표시합니다. 정상 발표 때는 끄는 것을 추천합니다.

### DXcam 오류가 발생한다면

Intel 내장 GPU와 NVIDIA 외장 GPU를 사용하는 노트북은 DXGI 기반 캡처에서 `0x887A0004` 오류가 발생할 수 있습니다. 이는 반드시 그래픽카드 4GB 메모리 부족을 의미하지 않습니다.

다른 엔진을 시도하거나, 이미 잘 작동하는 MSS 모드로 고정하면 됩니다.

```bat
set PPT_CAPTION_CAPTURE_MODE=mss
python main.py
```

기본 자동 시도 모드로 되돌리기:

```bat
set PPT_CAPTION_CAPTURE_MODE=auto
python main.py
```

명령 프롬프트 세션에만 적용되는 환경변수입니다. 캡처 창을 다른 창으로 가리거나 최소화하지 마세요.

이 저장소에 **개인 PPT, 발표 대본, 수정된 자막 JSON, 음성 녹음, 회의 영상, 암호나 API 키를 올리지 마세요.** `.gitignore`로 일반적인 형식은 제외했지만 이미 Git에서 추적 중인 파일은 자동으로 제거되지 않습니다.

프로그램 자체는 발표자 노트를 네트워크로 업로드하지 않습니다. 다만 Zoom/Meet에서 참석자 출력창을 공유하면 회의 서비스의 일반적인 화면 공유 경로로 전송됩니다.

## 개발 및 검증

```bat
python -m unittest discover -s tests -v
python -m py_compile main.py caption_core.py translations.py
```

GitHub Actions는 Windows의 Python 3.12/3.14에서 **문법과 순수 Python 테스트**만 수행합니다. PowerPoint COM 연결, 실제 동영상·다중 모니터 캡처, Zoom/Meet 공유는 현장 검증이 필요합니다.

프로그램 개선 의견과 접근성 관련 이슈를 환영합니다. 이슈를 올릴 때에도 개인 발표 원고나 식별 가능한 내용을 첨부하지 않도록 주의해 주세요.

## 개발 로드맵 (향후 기능)

**오프라인 TTS(음성 합성)**를 추가하여 직접 발표·TTS 발표·혼합 발표를 선택할 수 있도록 할 계획입니다. 개인 맞춤형 음성인식과 한국어↔영어 번역도 장기 목표입니다. **v0.2.0에는 아직 포함되지 않습니다.** 세부 내용은 [개발 로드맵](ROADMAP.md)을 참고하세요.
